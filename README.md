# Wireshark-Network-Packet-Analysis-Project
This project demonstrates hands‑on experience capturing, analyzing, and interpreting network traffic using Wireshark. The analysis includes ICMP ping traffic, HTTP web traffic, Ethernet and IPv4 headers, TCP control flags, and packet sequences. The project also explores how VPN tunneling affects packet visibility.

# Tools
* Wireshark (packet capture & analysis)
* Windows PowerShell (commands: ipconfig, ping, arp -a)
* VPN (observed encrypted traffic behavior)

# Project
Full project breakdown can be found in the file above titles "Wireshark Project"

# Skills Demonstrated
* Network packet capture and protocol analysis
* Identifying MAC and IP addresses from Ethernet and IPv4 headers
* Using display and capture filters (ICMP, TCP, HTTP)
* Understanding TCP flags (SYN, ACK, FIN) and sequence numbers
* Validating gateway information using ARP tables
* Observing VPN tunneling effects on packet visibility

# Summary
This project provided practical experience in analyzing real network traffic, understanding protocol behavior, and interpreting packet‑level communication. It demonstrates foundational skills relevant to IT Support, Cybersecurity Analyst, SOC Analyst, and Network Technician roles.
